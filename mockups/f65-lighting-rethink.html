AULA F65 · lighting app concept

F65 Looks: change your keyboard in one move

The current app is organised the way the keyboard stores things: onboard lighting, live lighting, a 7-colour palette, side lights, restore point files. This concept is organised the way people think: how should my keyboard look right now? It borrows proven patterns from Hue, SignalRGB, Razer Chroma Studio, Logitech G HUB, Corsair iCUE and Wootility, and stays inside what the F65 can actually do.

Pick a LookOne gallery for everything. Hover to preview, click to apply, Undo to go back. The app decides whether it's saved on the keyboard or streamed.
Paint, don't configureDrag across keys, tap a region chip, fill, gradient. Per-key colour is a brush, not a settings screen.
Never open the windowFavourites in the menu bar, a shortcut to cycle them, and a ⌘K command bar: type "wasd red" or "dim 50".

Honest by design

How each idea maps to the hardware

Every interaction uses only the writes the app already allows (commands 01, 04 and 09) or the live stream. Packets are for 2.4G (14 bytes each, each one acknowledged); the cable sends one report per block.
